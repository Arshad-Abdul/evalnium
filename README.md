## 🌟 Overview

**Evalnium** is a commercial-grade, modern Web Application designed for creating, converting, and taking topic-wise multiple-choice online examinations.

### Key Highlights

- **🔒 Admin Passcode Studio**: Protected Admin Studio (Default Passcode: `admin123`) for converting documents (`.csv`, `.md`, `.docx`, `.txt`) into interactive MCQs.
- **🎓 Candidate Exam Portal**: High-speed, zero-friction Computer-Based Test (CBT) interface for candidates worldwide.
- **📊 Real-Time CBT Simulation**: Live countdown timer, Question Palette (🟢 Answered, 🟡 Review, 🔵 Current, ⚪ Skipped), clear selection, and submit confirmation modal.
- **💡 Guaranteed Rationale & Scorecards**: Instant percentage scores, accuracy metrics, and detailed answer key explanation callouts.
- **☀️ Light Mode Design System**: Built with modern UI guidelines (Tailwind CSS v4, Lucide icons, glassmorphism light panels).

---

## 🛠️ Technology Stack

- **Frontend**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism System
- **Parsers**: Mammoth.js (Word .docx), PapaParse (CSV), Custom Multi-Strategy Plain Text Engine
- **Icons**: Lucide React Icons
- **Animation**: Canvas Confetti (Passed Exam celebration)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Arshad-Abdul/evalnium.git

# Navigate to project directory
cd evalnium

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```
